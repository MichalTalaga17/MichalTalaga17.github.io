EdgeCoach

The Challenge

EdgeCoach is a privacy-first iOS speaking coach that helps users practice presentations, interviews, and high-pressure speaking in real time. It tracks pace, filler words, pauses, and tone using on-device processing.

Technologies

  • • SwiftUI for the UI
  • • AVFoundation for Audio processing
  • • SwiftData for local storage
  • • Custom AI Models for Speech Analysis

Key Results

Complete offline analysis with low latency and pixel-perfect design.
