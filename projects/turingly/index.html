The Challenge

Turing Simulator is a native macOS application built for high-performance exploration of Alan Turing's 1936 vision. It bridges historical computer science with modern UI, allowing users to build and test complex state-based algorithms.

Technologies

  • • Swift & SwiftUI for macOS
  • • macOS SDK Native Integration
  • • Apple Silicon Optimized Engine
  • • Real-time Logic Validation

Key Features

Step-by-step execution control, a logic editor, and a library of 40 built-in algorithms.
